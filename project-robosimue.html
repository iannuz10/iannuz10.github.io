RoboSimUE: High-Fidelity Hybrid Robotics Simulation Infrastructure

Unreal Engine 5 | C++ | Python | MuJoCo | Zenoh | Docker

Overview

RoboSimUE is a high-performance, decoupled robotics simulation environment designed to bridge the gap between photorealistic rendering and scientific physics. Traditional simulators often force a compromise between visual fidelity and physics performance. By decoupling the two, computational power is dedicated independently to each task.

The system operates on a Host-Guest Topology:

  • The Host (Unreal Engine 5): Handles high-fidelity rendering (Nanite/Lumen) and dynamic visual environments natively on Windows/Mac.
  • The Guest (Dockerized Linux): Acts as the logical "Brain," running MuJoCo and Python within a modular container.
  • The Bridge (Zenoh): A zero-overhead PUB/SUB networking layer that connects the Host and Guest via TCP, functioning as a high-speed DDS alternative.

Engineering Challenges & Performance

The primary engineering challenge in a decoupled simulation is network latency and thread synchronization. Achieving a seamless real-time Digital Twin requires bridging the 16.6ms rendering loop of Unreal Engine with the high-frequency physics ticks of MuJoCo.

  • Sub-2ms RTT Latency: By implementing an "Envelope Split" architecture, the network bridge completely bypasses the Unreal Engine Game Thread. C++ FRunnable background threads intercept incoming TCP packets, instantly bounce an ACK payload, and process JSON deserialization asynchronously.
  • Python Vectorization: On the Guest side, mathematical bottlenecks and Garbage Collection spikes were eliminated by abandoning native Python loops in favor of NumPy vectorization and orjson (a Rust-based serializer). The physics data is transformed and serialized entirely in C-memory space before transmission.
  • O(1) Memory Caching: Eliminated costly 60Hz string-comparison loops by building Just-In-Time (JIT) TMap caches and Weak Pointers in C++, tracking hundreds of joints and actors dynamically.

Core Capabilities

  • Stable 60Hz Physics Loop: A fully functional, bidirectional physics-to-visual loop using isolated Zenoh topics for state synchronization and latency telemetry.
  • Dynamic World Generation: Unreal Engine serializes the environment (static floors, dynamic props, custom meshes) into JSON. The Guest dynamically builds the physical MuJoCo worldbody entirely in memory upon initialization.
  • Native Robot Support (MJCF): Seamlessly parses and loads native .mjcf and .xml robotic models, fully supporting industry-standard repositories like mujoco_menagerie.
  • Custom Mesh Pipeline: Developed an automated asset pipeline utilizing Python to generate visual-only URDFs from MJCF files, allowing complex kinematic hierarchies to be imported into UE5 via Blender without transform degradation.
