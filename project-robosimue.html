RoboSimUE: High-Fidelity Hybrid Robotics Simulation Infrastructure

C++ Python Unreal Engine 5 MuJoCo Zenoh Docker
View Repository

Overview

RoboSimUE is a decoupled, high-performance robotics simulation environment designed to bridge the gap between photorealistic rendering and scientific physics. Traditional simulators often force a compromise between visual fidelity and physics performance. By decoupling the two architectures across a high-speed network bridge, RoboSimUE allows computational power to be dedicated to each task independently.

The system utilizes Zenoh as a lightweight, zero-overhead PUB/SUB networking layer to achieve sub-3ms latency (averaging ~1.7ms RTT) between the visual engine and the physics backend.

Architectural Design (Host-Guest Topology)

  • The Host (Unreal Engine 5): Acts as the "Body" and "Eyes". It is responsible for high-fidelity rendering (leveraging Nanite and Lumen), sensor simulation, and kinematic visualization.
  • The Guest (Dockerized Linux): Acts as the "Brain". It runs a containerized environment handling the physics calculations via MuJoCo and future control stacks via ROS 2.
  • Dynamic World Generation: The UE5 Host serializes the physical environment (static floors, props, custom meshes) into a payload. The Guest receives this and dynamically builds the physical worldbody entirely in memory on the fly.

Key Engineering & Optimizations

Achieving ultra-low latency for real-time digital twinning required strict systems engineering and performance optimization across both languages:

  • C++ Multithreading & Asynchronous Deserialization: Completely bypassed the UE5 Game Thread rendering bottleneck by implementing an FRunnable background thread. Network packets are caught and acknowledged instantly, parsing state updates asynchronously before handing clean data structs back to the Game Thread.
  • O(1) Memory Caching: Eliminated $O(N)$ string comparisons and array transversals from the 60Hz physics loop by implementing Just-In-Time (JIT) TWeakObjectPtr actor caching in C++ and dictionary-based manifest mapping in Python.
  • True Batch Vectorization: Utilized NumPy to vectorize coordinate transforms (e.g., Left-Handed to Right-Handed conversion, quaternion inversions) entirely in C-space, eliminating Python-level iteration overhead.
  • Modular Engine Agnosticism: Architected the backend using Abstract Base Classes (ABCs) and Pydantic data schemas, allowing the core network bridge to function independently of the physics engine. This enables future drop-in replacements like PyBullet or PhysX.

Envisioned Applications

  • Synthetic Data Generation: Leveraging UE5’s procedural generation capabilities to create environments for training World Models, Vision-Language-Action (VLA) models, and other vision-based learning systems.
  • VR Teleoperation & HRI: Fusing sensor data into the UE5 visual layer to allow users to teleoperate robots with high physical fidelity while completely immersed in a realistic digital twin.
  • Reinforcement Learning (RL): Providing superior domain-randomization value by training agents over realistic RGB image streams.
